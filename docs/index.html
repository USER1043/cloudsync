CloudSync

A personal background service that keeps one folder in sync across Windows, Linux and Google Drive.

What it does

CloudSync runs quietly on a dual-boot laptop. It mirrors a chosen local folder to a single folder in the user's own Google Drive:

  • When a file is created, edited, renamed or deleted, the change is uploaded to Google Drive.
  • When the user logs in to the other operating system, CloudSync downloads whatever changed in the meantime.
  • Because the files live in Google Drive, they can also be opened from a phone through the Google Drive app.

Who it is for

CloudSync is a personal, non-commercial project used only by its developer on their own devices and their own Google account. It is not offered as a service to other people.

How it uses Google Drive

CloudSync signs in with Google OAuth and uses the Google Drive API to upload, download, list and create share links for files inside its own sync folder. Data travels only between the user's computer and the user's Google Drive. There is no CloudSync server. Details are in the privacy policy.
