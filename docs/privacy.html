Privacy Policy

CloudSync · Effective 27 October 2026

CloudSync is a personal, non-commercial file sync tool that runs on its developer's own computers and works with their own Google account. This policy explains what Google user data CloudSync accesses and how that data is handled.

Data CloudSync accesses

After the user signs in with Google and grants permission, CloudSync uses the Google Drive API to:

  • list files and folders, and read their metadata (names, sizes, checksums, modification times and change history), so it can tell what changed;
  • download and upload file contents inside its sync folder;
  • move files to the Google Drive trash when they are deleted locally;
  • create sharing links, only when the user explicitly asks for one.

CloudSync only works inside its own sync folder in Google Drive. It does not read Gmail, Contacts, Calendar, Photos or any other Google service.

How the data is used

Google user data is used only to keep the user's local folder and their Google Drive folder identical. It is not used for advertising, analytics, profiling, or training machine-learning models.

Where the data is stored

  • Files are stored only on the user's own computer and in the user's own Google Drive.
  • Sign-in tokens are stored in the operating system's secure credential store (Windows Credential Manager or KDE Wallet) on the user's computer.
  • Sync state (file names, paths, checksums and timestamps) is kept in a local database on the user's computer.

CloudSync has no server. No data is sent to the developer or to any party other than Google.

Sharing

CloudSync does not sell, rent, transfer or disclose Google user data to anyone. Files are shared only when the user explicitly creates a sharing link for a specific file.

Limited Use

CloudSync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Local sync state and tokens remain on the user's computer until CloudSync is uninstalled or its data folder is deleted. Access can be revoked at any time at myaccount.google.com/permissions. Files in Google Drive remain under the user's control and are never deleted by CloudSync except to mirror a deletion the user made locally, and those go to the Google Drive trash.

Changes

If this policy changes, the updated version will be published on this page with a new effective date.
